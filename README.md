# Dungeon Explorer

A console-based dungeon exploration game written in C++ for a data structures course.

## How to Build and Run

### Prerequisites
- C++ compiler with C++11 support (`g++`)
- `make` build utility

### Build
To compile the project, run:
```bash
make
```

### Run
To launch the game:
- On Linux / macOS / Git Bash:
  ```bash
  ./dungeon_explorer
  ```
- On Windows:
  ```cmd
  dungeon_explorer.exe
  ```

Or run directly through make:
```bash
make run
```

### Clean
To clean up compiled binaries and build artifacts:
```bash
make clean
```
